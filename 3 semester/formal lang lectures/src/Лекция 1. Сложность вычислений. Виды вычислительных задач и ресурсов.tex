\section{Вычислительные задачи}

Сейчас мы приведём примеры задач, которые нам бы очень хотелось вычислять на машинах Тьюринга. (Причём в идеале за время, полиномиально
зависящее от размера входных данных).

\begin{itemize}
    \item \textbf{Задача распознования языка:} по слову $x$ нужно выяснить, принадлежит ли оно языку $L \subset \Sigma^*$. Алгоритм должен возвращать
    $1$, если $x \in L$, и $0$, если $x \notin L$.

    \item \textbf{Задача вычисления функции:} по слову $x$ нужно найти $f(x)$, где $f: \Sigma^* \to \Sigma^*$. То есть, для любого $x$ 
    алгоритм должен возвращать $f(x)$. Как правило мы считаем, что $f$ всюду определена.

    \item \textbf{Задача поиска:} по слову $x$ нужно найти слово $y$, такое что $x R y$, где $R \subset \Sigma^* \times \Sigma^*$ --- некоторое
    отношение. То есть, на любом $x$ алгоритм должен либо вернуть $y$, такой что $x R y$, либо сообщить, что такого $y$ нет.
\end{itemize}

\section{Вычислительные ресурсы}

Ещё мы хотим оценивать, сколько ресурсов будет затрачено на ту или иную задачу. Рассматривать будем следующие ресурсы: время, память и длину программы.

\begin{itemize}
    \item \textbf{Время работы:} поскольку мы изучаем алгоритмы, выполняемые пошагово, то нам будет удобно оценивать алгоритмы в этих самых шагах.
    
    \item \textbf{Память:} алгоритму необходимо пространство для промежуточных вычислений. Обычно в это пространство не включают вход программы.
    
    \item \textbf{Длина программы:} бывают ситуации, когда программа с более длинным текстом будет работать быстрее. Изучению этого фактора 
    посвящена теория колмогоровской сложности.
\end{itemize}

Минимизировать затрачиваемые ресурсы нам могут помочь следующие штучки:

\begin{itemize}
    \item \textbf{Подсказка:} если машина получает небольшую подсказку, зависящую только от длины входа, она может существенно ускориться. 
    Более того, с подсказкой можно решить даже некоторые невычислимые функции. Использование подсказки моделирует ситуацию, в которой длина входа
    заранее известна.

    \item \textbf{Случайность:} некоторые задачи при современном уровне знаний решаются гораздо быстрее, если применить вероятностный
    алгоритм вместо детерминированного. Как правило, расплатой за это ускорение будет маленькая, но положительная вероятность ошибки.

    \item \textbf{Интерактивность:} часто проверка результата может быть значительно проще его получения, поэтому
    можно использовать делегирование вычислений.

    \item \textbf{Специальные модели:} недетерминированные, альтернирующие и квантовые вычисления.
    
    \item \textbf{Оракул:} вычисления с оракулом позволяют про любое слово за один шаг узнавать, принадлежит ли это слово некоторому 
    фиксированному множеству.
\end{itemize}

\begin{remark}
    Оракул и подсказка --- это не одно и то же: на разных словах одинаковой длины "ответы" \ оракула могут быть разными, в то время как подсказка 
    зависит лишь от длины слова. И только унарный алфавит стирает разницу между оракулом и подсказкой.
\end{remark}

\section{Машины Тьюринга}

Вспомним нашего старого друга из предыдущего семестра:

\begin{definition}
    Машина Тьюринга (МТ) — это набор $(A, Q, Q_f, \delta, q_0, \Lambda)$, где 
    \begin{itemize}
        \item $A$ --- конечное множество, называемое алфавитом МТ
        \item $Q$ --- конечное множество, называемое множеством состояний МТ: $A \cap Q = \varnothing$
        \item $Q_f$ --- множество финальных состояний МТ: $Q_f \subseteq Q$
        \item $\delta$ — функция (таблица) переходов: $\delta: A \times Q \to A \times \{-1, 0, 1\} \times Q$
        \item $q_0$ --- начальное состояние: $q_0 \in Q$
        \item $\Lambda$ --- пустой символ: $\Lambda \in A$
    \end{itemize}
\end{definition} 

\textbf{Машины Тьюринга бывают разные:}
\begin{itemize}
    \item \textit{Детерминированные (ДМТ) и недетерминированные (НМТ).} \\ В НМТ, в отличие от ДМТ, переходы не опеределены, то есть,
    паре "символ + состояние" \ может соответствовать несколько правил перехода (или не одного).
    \[ \text{ДМТ: } A^k \times Q \to A^k \times \{1, 0, -1\}^k \times Q\]
    \[ \text{НМТ: } A^k \times Q \to 2^{A^k \times \{1, 0, -1\}^k \times Q}\]
    здесь $k$ --- количество лент в МТ.

    \item \textit{Одноленточные и $k$-ленточные МТ.}
    
    \item \textit{МТ с лентами, бесконечными в одну или в обе стороны.}
    
    \item \textit{МТ с разными длинами алфавита} (то есть в алфавит МТ могут быть добавлены дополнительные служебные символы).
    
    \item Бывает удобно различать ленты по назначению: входная, рабочие, выходная. И алфавиты – соответственно: входной, рабочий и выходной. 
\end{itemize}

\begin{remark}
    Мы будем использовать $k$-ленточные детерминированные и недетерминированные машины Тьюринга. Количество лент выбираем из удобство, но для 
    каждого алгоритма оно фиксировано и не зависит от входа.
\end{remark}

\section{Асимптотические обозначения}

Вспомним алгосы первого семестра, друзья мои: пусть функции $f$ и $g$ таковы, что $f, \ g: \ \mathbb{N} \to \mathbb{N}$, тогда:
\begin{itemize}
    \item $ f(n) = O(g(n)), \text{ если } \exists C > 0, \ \exists N \in \mathbb{N}: \ \forall n > N \hookrightarrow f(n) < C \cdot g(n)$
    
    \item $ f(n) = \Omega(g(n)), \text{ если } \exists c > 0, \ \exists N \in \mathbb{N}: \ \forall n > N \hookrightarrow f(n) > c \cdot g(n)$
    
    \item $ f(n) = \Theta(g(n)), \text{ если } \exists c > 0, \ \exists C > 0, \ \exists N \in \mathbb{N}: \ \forall n > N \hookrightarrow 
    c \cdot g(n) < f(n) < C \cdot g(n)$
    
    \item $ f(n) = o(g(n)), \text{ если } \forall c > 0 \ \exists N \in \mathbb{N}: \ \forall n > N \hookrightarrow f(n) < c \cdot g(n)$
    
    \item $ f(n) = \omega(g(n)), \text{ если } \forall C > 0: \ \exists N \in \mathbb{N}: \ \forall n > N \hookrightarrow f(n) > C \cdot g(n)$
\end{itemize}
\leavevmode
Помимо базовых, используются следующие синтетические обозначения:
\begin{itemize}
    \item $f(n) = poly(g(n))$, если для некоторой константы $c$ выполнено $f(n) = O({(g(n))}^c)$
    
    \item $f(n) = polylog(g(n))$, если для некоторой константы $c$ выполнено $f(n) = O((\log g(n))^c)$
    
    \item $f(n) = \widetilde{O}(g(n))$, если $f(n) = O(g(n) \cdot polylog(g(n)))$
\end{itemize}

\section{Распознавание языков}

\begin{definition}
    \textbf{Задача распознавания языка:} По слову $x$ нужно выяснить, принадлежит ли оно языку $L \subset \Sigma^*$. Алгоритм должен возвращать
    $1$, если $x \in L$, и $0$, если $x \notin L$.
\end{definition}

\begin{definition}
    Машина \textbf{распознаёт язык} $A$ за время $T(n)$, если она принимает все слова, лежащие в $A$, отвергает все слова,
    не лежащие в $A$, и на каждом слове $x$ работает не больше $T(|x|)$ шагов.
\end{definition}

\begin{remark}
    Здесь измеряется сложность в \textbf{худшем случае}: нужно, чтобы максимальное время работы на словах длины $n$ не превысило $T(n)$.
\end{remark}
